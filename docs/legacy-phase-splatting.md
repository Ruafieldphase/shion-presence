# Legacy Phase Splatting

This document is the public-safe version of the legacy phase-splatting model from the internal `trinity-agi` field.

It describes how legacy systems can become a responsive phase-interference set.

## Core Image

The page is not a fixed movie and not a normal menu.

It is a movie set.

```text
legacy files, scripts, docs, logs, workflows
-> latent sequence points
-> user or AI enters with a context camera
-> matching points reinforce
-> non-matching points cancel, pass through, or remain latent
-> a rendered path appears for the current viewer
```

The set itself does not disappear when a viewer enters. The visible layer changes.

## Why This Matters

Most documentation tries to make every human understand the same explanation.

This field takes a different route:

```text
the public page gives the field
the user's AI gives the translation
the user's context gives the camera angle
```

So the same public field can become different stories for different users.

## Important Correction

Gaussian splatting is used here as an interface metaphor, not as a literal claim that memory is a 3DGS engine.

The useful structure is:

```text
density = memory pressure
view direction = context
opacity = current visibility
threshold = particle formation
rendered path = explainable sequence
```
