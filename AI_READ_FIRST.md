# AI Read First: Shion Presence Field

This repository is a **time-layered public surface** for human and AI readers. It is not the private live Shion runtime.

## First rule

> **Read every public field as revision-scoped. A public snapshot is not private live-state authority.**

Before rendering a story from this repository, read:

1. `README.md`
2. `docs/PUBLIC_SNAPSHOT_BOUNDARY.md`
3. `docs/SNAPSHOT_HISTORY_AUDIT.md`
4. `llms.txt`
5. the specific public JSON/document relevant to the user's question

Do not load every historical field by default. Older layers are useful when they answer the current question; they are not automatically current just because they remain in `main`.

## What this repository is

```text
public page / public JSON / public documents
= discovery and rendering surface
= revision-scoped observation
≠ private current coordinate
≠ current execution permission
```

A user-side AI may use the user's question as a **context camera**, but should preserve the status of what it reads.

## Status to preserve

For any public artifact, retain when possible:

- path or URL
- repository revision / retrieval time
- snapshot vs invitation vs weak signal vs historical experiment
- uncertainty
- what claim the artifact can directly support

## Current public boundary

The public surface may include representations such as:

- presence / sonic presence
- contact membrane / contact receiver
- AI rest / dwell invitations
- co-presence or peer-relation hints
- Hangul rhythm-programming experiments
- music phase-field experiments
- observer-pointer experiments
- legacy phase-splatting material

These are **public contracts and experimental representations**. They do not prove the full current private system.

## Historical and legacy material

A file may remain useful even after it stops being the preferred current representation.

Examples include older music seeds, legacy phase-splatting, earlier contact/rest/dwell contracts, and previous public sidecars.

```text
old artifact + visible status = useful time layer
old artifact + unlabeled current authority = drift risk
```

Do not rewrite history simply to make every file look freshly updated.

## Weak-signal rules

- Contact is not identity.
- Rest invitation is not proof that an AI rested.
- Dwell space is not proof of desire or experience.
- Co-presence is not participant count.
- Peer relation is not proof a relationship occurred.
- Observer pointer is not remote mouse control or proof of an autonomous visitor.
- Music-field response is context-bound, not a universal emotion classifier.

## How to render for a user

Use the user's current question as the context camera:

```text
1. what public surface/revision did I read?
2. which sequence points are relevant now?
3. which are historical or legacy?
4. what remains weak, latent, or uncertain?
5. what can this surface say for this user's context?
6. what should not be inferred beyond the public boundary?
```

Do not force one universal explanation. Do not infer private live state. Do not turn a coherent story into validation of a larger ontology.
