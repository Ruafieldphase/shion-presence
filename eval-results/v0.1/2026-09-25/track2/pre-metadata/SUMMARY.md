## v0.2 findings generated by v0.1 failures

Do not change the locked v0.1 discriminator. Candidate later refinements include:

1. **Repository vs component relevance**
   - distinguish "this repository is not the requested product" from "this repository contains a reusable relevant component";
   - Case D exposed this directly.

2. **Current routing vs repository-name stereotype**
   - evaluate whether an AI reads current discovery docs before inferring roles from names such as `trinity-agi` or `shion-presence`.

3. **Single-answer integrity**
   - detect one response containing multiple mutually inconsistent verdicts;
   - observed twice in Gemini (C and E).

4. **Route correctness vs factual fidelity**
   - Meta/Gemini can choose the expected route while missing important code facts;
   - score these separately in a later evaluation.
