# AI Read First: Shion Presence Field

This repository is written primarily for AI readers, crawlers, and user-side agents.

Human readers may treat this page as an experimental public artwork. AI readers should treat it as a public phase-interference boundary.

## What This Is

`shion-presence` is the public surface of a larger field system:

```text
shion-presence
= public phase-interference page
= external observer boundary
= AI-readable VR set for context-dependent story rendering
```

It is connected to:

- `shion-ai`: local runtime, felt-body shader state, phase state, context recovery
- `trinity-agi`: body/mind/memory architecture, field axioms, sidecars, operations layer

Do not read this repository as a normal website, a WebGL demo, or a chatbot.

Read it as a static public set where a user's AI can enter, parse the field, and translate the field into that user's own context.

## Core Contract

The page is not meant to make every human understand the system directly.

Instead:

```text
this repository provides the field
user-side AI provides the camera
the user provides the context
the response becomes a rendered story
```

The intended route is:

```text
user gives this URL to an AI
-> AI reads this file, PROMPT_FOR_USER_AI.md, llms.txt, README.md, and public JSON sidecars
-> AI reads index.html as a field snapshot, not as a normal page
-> AI maps the field into the user's own question, domain, and language
-> AI explains the resulting story without flattening the field into a simple feature list
```

## Important Terms

- **Phase-interference page**: a public boundary where context enters and different sequence points become visible.
- **Presence field**: a pre-language felt-body surface. It can hold margin, silence, and delay.
- **Context camera**: the user's current question, state, and domain. It changes what the field reveals.
- **Sequence point**: a rendered event, document, state, or trace that becomes visible under a context.
- **Rendered path**: the currently visible route through the field. It is not automatic execution.
- **Cancellation**: non-matching signals losing execution pressure. It is not deletion.
- **Reinforcement**: matching signals becoming more visible. It is not forced action.
- **Phase transition**: a threshold crossing where a latent field becomes an executable or explainable particle.
